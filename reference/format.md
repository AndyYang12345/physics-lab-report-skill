# 模板结构、锚点与字段对照

## 关于模板

**本仓库不附带任何学校的实验报告模板文件。** 模板是各学院自己印发的文档，
版权归原单位，由使用者自备。

准备方式：

1. 拿到你所在学校/学院的实验报告模板（通常是 `.docx`）；
2. **把里面的示例、批注、说明性文字全部删掉**，只留空白表单结构；
   - 很多模板用**红色文字**写排版要求（如"正文宋体，小四号，1.5 倍行距"），
     这些是给学生的提示，不是报告内容，要删；
   - 顺便记下这些要求，填进 `labkit.py` 顶部的格式常量；
3. 放到 `$PHYSLAB_HOME/templates/实验报告模板-空白.docx`，
   或设 `PHYSLAB_TEMPLATE` 指向它。

> 为什么强调"先读模板"：格式规范往往不在任何单独的文件里，
> 而是以批注形式**藏在模板内部**。不把它拆开读一遍，脚本就不知道该用什么字号。

## 本 Skill 默认假设的模板结构

`labkit.py` 的定位逻辑基于下面这套结构。若你的模板不同，按「定位锚点」一节改。

| 位置 | 内容 | 是否填写 |
| --- | --- | --- |
| 封面 | 校徽 + 「实验报告」标题 | 不动 |
| 封面表（5 行 2 列） | 课程名称 / 姓名 / 学号 / 专业班级 / 开课学期 | ✅ 从 `.profile` 填 |
| 前置说明页 | 学生守则、撰写要求等 | 不动 |
| 正文首页 | 标题「实验 」+ 信息行两行 | ✅ 填 |
| 正文页 | 正文表（1 行 1 列） | ✅ 填 |
| 末页 | 原始数据记录表 | ✅ 数据模式填 |

## 定位锚点

`labkit.py` **只用模板自带的固定标签定位，绝不用正文内容**——正文每次都不一样，
不能当锚点。（早期版本按正文句子插图，换一个实验就失效。）

| 要改什么 | 锚点 | 代码位置 |
| --- | --- | --- |
| 封面表 | 表格 `cell(0,0)` 文本 = `课程名称` | `build_report()` |
| 标题段 | 段落文本恰好 = `实验` | `build_report()` |
| 信息行 1 | 段落以 `实验日期：` 开头 | `build_report()` |
| 信息行 2 | 段落以 `实验时段：` 开头 | `build_report()` |
| 正文表 | 表格 `cell(0,0)` 文本以 `实验目的` 开头 | `build_report()` |
| 原始数据记录表 | 表格 `cell(0,0)` 文本 = `实验名称` | `fill_record_head()` |
| 记录表标题 | 段落以 `原始数据记录表` 开头（在此加 page_break_before） | `fill_data()` |

**换模板时改这些锚点即可**，其余逻辑不用动。

## 信息行的填空位

信息行靠**下划线 run** 表示填空位，`underlined_runs()` 按出现顺序取：

```
实验日期：[0]      姓名：[1]      座位号：[2]
实验时段：[0][1][2]   专业：[3][4][5]   指导老师：[6][7][8]
```

每组只有第一个 run 写值，其余清空（`set_blank()` 已处理）。
注意：**行末那组的下划线在右对齐排版里会被吞掉**，所以最后一格必须有真实文字
才看得见下划线——填上内容就正常了。

## 字段对照

| `.profile` 键 | 填到哪 |
| --- | --- |
| 课程名称 / 姓名 / 学号 / 专业班级 / 开课学期 | 封面表第 2 列 |
| 姓名 / 座位号 | 信息行 1 |
| 实验时段 / 专业 / 指导老师 | 信息行 2 |
| 实验名称 / 姓名 | 原始数据记录表表头 |
| 座位号 / 姓名 / 实验名称 | **提交文件名** |

## 分页行为（重要）

- **正文表**行高较大（本模板 20cm，atLeast），内容含插图超长时会自动跨页增高——
  正常，不要试图压缩。
- **原始数据记录表**的大行高会把表头挤到上一页。`fill_data()` 因此做了两件事：
  把该行降到 15cm 自适应，并给「原始数据记录表」标题加 `page_break_before`。
  **别删这些处理**，否则表头和数据会被拆到两页。
- LibreOffice **不认表格单元格内的 `keep_with_next`**，插图与题注仍可能被拆页。
  代码已设该属性（Word 里有效），但**每次导出后仍要目视核对 PDF**。

## 格式常量

定义在 `labkit.py` 顶部，换学校改这里即可全局生效：

```python
FONT     = '宋体'
SZ_COVER = 32   # 三号：封面字段
SZ_BODY  = 24   # 小四：正文
SZ_CAP   = 21   # 五号：图表题注
SZ_TABLE = 24   # 小四：数据表
LINE     = 1.5  # 正文行距
```
